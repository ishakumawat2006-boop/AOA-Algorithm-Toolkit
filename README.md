# AOA Algorithm Toolkit

## 📌 Project Overview

AOA Algorithm Toolkit is an Analysis of Algorithms project developed in C++.
It provides a menu-driven implementation of fundamental sorting, graph,
optimization, and backtracking algorithms.

The project demonstrates the implementation, working, and complexity
of important algorithms studied in Analysis of Algorithms.

## 🎯 Objectives

- To implement fundamental algorithms using C++.
- To understand the working of different algorithmic techniques.
- To analyze the time and space complexity of algorithms.
- To provide a simple menu-driven interface for testing algorithms.

## 🚀 Algorithms Implemented

### Sorting Algorithms
- Quick Sort
- Merge Sort

### Graph Algorithms
- Dijkstra's Algorithm
- Prim's Algorithm
- Kruskal's Algorithm
- Floyd-Warshall Algorithm
- Topological Sorting
- Warshall's Algorithm

### Optimization Algorithms
- 0/1 Knapsack
- Travelling Salesman Problem (TSP)

### Backtracking
- N-Queens Problem

## 🛠️ Technologies Used

- C++
- C++ Standard Template Library (STL)
- GitHub

## ▶️ How to Run

1. Download or clone this repository.
2. Open `AOA_Algorithm_Toolkit.cpp` in a C++ IDE.
3. Compile the program using a C++ compiler.
4. Run the executable.
5. Select the required algorithm from the menu.

### Compile and Run

```bash
g++ AOA_Algorithm_Toolkit.cpp -o AOA_Toolkit
./AOA_Toolkit
